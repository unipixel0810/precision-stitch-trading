# Smart Money 감지와 Stitch 시스템 매핑

트레이딩 가설(세력 잔류 vs 차익 실현)을 제품·도메인 설계 언어로 정리한 문서다. 구현은 별도 Phase에서 Port·유스케이스로 쪼갠다.

---

## 1. 거래량 비대칭성 (세력 잔류 vs 이탈)

**핵심:** 올릴 때 터진 거래대금과 눌릴 때의 거래량 대비.

### 매수(세력 잔류) 쪽 해석

- 최근 1~3거래일 안에 **역대급 거래대금**(운영 기준 예: **5000억 이상**)을 동반한 **장대 양봉**이 있었고,
- 현재 가격은 그 이후 **눌림**인데,
- 거래량이 그 양봉 시점 대비 **대략 1/10 이하**로 **급감**했다면,

→ “적극적 매도 유입은 약하고, 물량이 한쪽에 쌓여 있을 수 있다”는 **가설 근거**로 쓸 수 있다. (단독 확증 아님)

### 회피(차익 실현/Exit) 쪽 해석

- 가격은 **유지·소폭 상승**인데,
- **이전 고점 대비 더 큰 거래량**이 터지며,
- **윗꼬리가 길게** 달리면,

→ 개인 쪽으로 물량이 넘어가며 세력이 줄이는 패턴으로 **회피 후보**로 둔다.

## 2. 매물대: 악성 매물 소화 여부

- 매물대를 **뚫었다** = 그 가격대 물량이 상당 부분 **소화**되었다는 **해석** (절대 아님).
- **매물대 상단 돌파 후 안착:** 최근 **거래가 가장 많이 터진 구간(매물대)** 위에서, 주가가 **캔들 몸통**으로 버티는지 본다.

### Stitch 적용 (개념)

- 매물대 상단(또는 돌파 확인 가격)을 **「Stitch 매수선」(기준선)** 으로 둔다.
- 가격이 그 선 **아래로 되돌아오지 않고 지지**가 반복되면, “가격 방어·관리” 가설을 **강화**한다는 뜻으로만 사용한다.

## 3. Smart Money Detection Logic (시스템·AI용 체크리스트)

아래는 **자동 태깅·스캐너 필터·알림** 설계 시 쓸 수 있는 **조건 초안**이다. 임계값은 백테스트·운영 기준으로 조정한다.

| ID | 이름 | 조건(초안) |
|----|------|------------|
| SM-1 | Massive volume | 최근 **5거래일** 이내, **당일 평균 거래대금 대비 500% 이상**의 거래대금을 동반한 **양봉** 존재 |
| SM-2 | Low volume retracement | 고점 대비 **-5%~-10%** 눌림 구간에서, 거래량이 위 양봉 시점 대비 **20% 미만** |
| SM-3 | Order stack (키움) | 호가창에서 **매수 호가** 측에 **반복적 물량 방어** 패턴 (데이터는 연동 후 정의) |
| SM-4 | Stitch Base Line | **최대 거래대금 양봉의 시가** 또는 **매물대 상단**을 **매수 기준선**으로 고정 |
| SM-5 | 세력 이탈(손절 트리거) | Base Line **이탈(예: 시가 이탈 종가 확정)** 시 “세력 이탈 감지”로 **기계적 손절** 후보 |

## 4. Stitch 시스템 시나리오 (UI·역할 매핑)

| 구성요소 | 역할 |
|----------|------|
| **Scanner** | 거래대금 **5000억+** 양봉 등 **필터·랭킹** 후보 노출 |
| **Chart** | 최대 거래대금 봉의 **기준선(시가/중심)** · **매물대 상단** 오버레이 (현재는 이미지 배경+가격선 모델 확장 여지) |
| **Interaction** | 사용자가 “잔류” 판단 시 **1차 매수**를 그 기준선·Stitch 라인에 맞춤 |
| **Safety** | Base Line 이률 시 **알림 + 리스크(손절) 자동 제안/실행** (정책은 규제·계좌 연동 후) |

## 5. 아키텍처에 넣을 때 (요약)

- **Domain:** `VolumeProfileBar`, `SmartMoneySignal`(enum flags), `StitchBaseLine`(가격·출처: max-volume-open / supply-top) 등 값 객체 후보.
- **Application:** `EvaluateSmartMoneySignals` 같은 조합 유스케이스, 스캐너용 `ScanHighMoneyFlowCandidates`.
- **Infrastructure:** 키움/증권사 API·호가 스냅, 일봉·거래대금 집계.
- **Presentation:** 차트 오버레이, 스캐너 칩(SM-1~2 충족 등), Controller SL/TP와 Base Line 연동 문구.

이 문서는 `docs/PHASE1_EXPANSION_SLOTS.md`의 스캐너·차트·알림 슬롯과 함께 본다.
